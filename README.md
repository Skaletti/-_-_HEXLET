# Организация экзамена 
- Экзамен состоит из устной теоретической части и практического задания.,
- Теоретическая часть: студент отвечает на вопросы из общего перечня. Преподаватель может задать уточняющие вопросы и попросить привести пример кода.
- Практическая часть: студент реализует программу на JavaScript с помощью Node.js, объясняет принятые решения и демонстрирует работу на исходных данных.
- При оценивании учитываются корректность результата, понимание принципов работы JavaScript, читаемость кода, обработка граничных случаев и способность объяснить решение.
