# Экзамен по JavaScript — вариант 1

## Теоретические вопросы

1. **Функции в JavaScript.** Чем отличаются объявление функции, функциональное выражение и стрелочная функция? Приведите примеры.
2. **Условные операторы и циклы.** Когда применяются `if/else`, `switch`, `for`, `while` и `for...of`? Как избежать бесконечного цикла?
3. **Массивы и объекты.** Как получить доступ к элементам массива и свойствам объекта? Как перебрать элементы массива и свойства объекта?
4. **Методы массивов.** Объясните назначение `map`, `filter` и `reduce`. Приведите пример практической задачи для каждого метода.
5. **Деструктуризация.** Как извлекать значения из массивов и объектов, задавать значения по умолчанию и переименовывать свойства?
6. **Поверхностное и глубокое копирование.** Чем они отличаются? Почему копирование объекта через spread не копирует вложенные объекты независимо?

## Практическое задание: каталог библиотеки

Дан массив книг:

```js
const books = [
  { id: 1, title: "Дюна", author: "Фрэнк Герберт", year: 1965, available: true, rating: 9 },
  { id: 2, title: "Солярис", author: "Станислав Лем", year: 1961, available: false, rating: 8 },
  { id: 3, title: "Нейромант", author: "Уильям Гибсон", year: 1984, available: true, rating: 8 },
  { id: 4, title: "Основание", author: "Айзек Азимов", year: 1951, available: true, rating: 9 },
  { id: 5, title: "Солярис", author: "Станислав Лем", year: 1961, available: true, rating: 7 }
];
```

Напишите программу, которая выполняет следующие действия:

1. Реализуйте `getAvailableBooks(books)`, возвращающую новый массив доступных книг.
2. Реализуйте `getBookTitles(books)`, возвращающую массив названий книг.
3. Реализуйте `getAverageRating(books)`, вычисляющую средний рейтинг книг. Предусмотрите случай пустого массива.
4. Реализуйте `countBooksByAuthor(books)`, возвращающую объект, в котором ключ — имя автора, а значение — количество его книг в массиве.
5. Реализуйте `updateBookRating(book, newRating)`, которая возвращает копию книги с новым рейтингом и не изменяет исходный объект.
6. Реализуйте `printBook({ title, author, year })`, выводящую информацию о книге с использованием деструктуризации.
7. Создайте функцию с параметром rest, принимающую любое количество книг и возвращающую их количество. Покажите вызов с использованием spread.
8. Проверьте решение на пустом массиве и объясните, какие функции изменяют исходные данные, а какие возвращают новые.
