# Экзамен по JavaScript — вариант 2

## Теоретические вопросы

1. **Параметры и возвращаемое значение функции.** Чем параметры отличаются от аргументов? Что возвращает функция, если в ней отсутствует `return`? Как работают значения параметров по умолчанию?
2. **Объекты и передача данных в функции.** Что происходит, когда функция получает объект в качестве аргумента? Как изменение свойства объекта внутри функции может повлиять на исходные данные?
3. **Операторы rest и spread.** Чем они отличаются по назначению? Покажите примеры для массивов, объектов и параметров функции.
4. **Функции высшего порядка.** Что делает функцию функцией высшего порядка? Приведите пример функции, которая принимает другую функцию аргументом.
5. **Рекурсия и итерация.** Чем отличаются рекурсивный и итеративный процессы? Что такое базовый случай рекурсии и почему он необходим?
6. **Абстракция и интерфейс как контракт.** Зачем отделять назначение функции от деталей её реализации? Как понятный интерфейс помогает заменить реализацию, не меняя остальной код?

## Практическое задание: учёт результатов студентов

Дан массив результатов:

```js
const results = [
  { student: "Алексей", subject: "JavaScript", score: 85, passed: true },
  { student: "Мария", subject: "JavaScript", score: 92, passed: true },
  { student: "Илья", subject: "JavaScript", score: 48, passed: false },
  { student: "Алексей", subject: "SQL", score: 74, passed: true },
  { student: "Мария", subject: "SQL", score: 59, passed: false }
];
```

Напишите программу, которая выполняет следующие действия:

1. Реализуйте `getPassedResults(results)`, возвращающую новый массив результатов с оценкой не ниже 60.
2. Реализуйте `getStudentNames(results)`, возвращающую массив имён студентов без повторов.
3. Реализуйте `getAverageScore(results)`, вычисляющую средний балл. Предусмотрите случай пустого массива.
4. Реализуйте `getAverageBySubject(results)`, возвращающую объект, где ключ — название предмета, а значение — средний балл по нему.
5. Реализуйте `updateScore(result, newScore)`, возвращающую копию записи с новым баллом без изменения исходного объекта.
6. Реализуйте `printResult({ student, subject, score, passed })`, выводящую результат с помощью деструктуризации.
7. Реализуйте функцию высшего порядка `filterResults(results, predicate)`, которая принимает условие в виде функции и возвращает подходящие записи. Покажите пример вызова.
8. Создайте функцию с параметром rest для подсчёта количества переданных записей и вызовите её с массивом через spread.
9. Объясните, как можно изменить правило определения успешной сдачи, не переписывая функции вывода результатов.
