# Экзамен по JavaScript — вариант 3

## Теоретические вопросы

1. **Область видимости переменных.** Чем отличаются `let`, `const` и `var`? Что означает область видимости и почему важно учитывать место объявления переменной?
2. **Агрегация данных.** Что означает агрегировать массив объектов? Как решить задачу подсчёта, суммирования или группировки данных с помощью цикла или `reduce`?
3. **Истинные и ложные значения.** Что такое truthy- и falsy-значения? Как они используются в условных операторах?
4. **Поверхностное и глубокое копирование.** Приведите пример вложенного объекта. Что произойдёт с вложенными данными при копировании через spread и как создать независимую копию на нужную глубину?
5. **Функции высшего порядка.** Чем полезны функции, которые принимают другие функции или возвращают их? Приведите пример использования.
6. **Абстракции и интерфейсы.** Как выделить понятный набор операций для работы с данными? Почему код, использующий общий интерфейс функции, может не зависеть от конкретного способа её реализации?

## Практическое задание: корзина интернет-магазина

Дана корзина товаров:

```js
const cart = [
  { id: 1, name: "Клавиатура", price: 3500, quantity: 1, category: "Периферия" },
  { id: 2, name: "Мышь", price: 1800, quantity: 2, category: "Периферия" },
  { id: 3, name: "Монитор", price: 18000, quantity: 1, category: "Экраны" },
  { id: 4, name: "Кабель", price: 700, quantity: 3, category: "Аксессуары" }
];
```

Напишите программу, которая выполняет следующие действия:

1. Реализуйте `calculateCartTotal(cart)`, вычисляющую стоимость всей корзины с учётом количества каждого товара.
2. Реализуйте `getExpensiveProducts(cart, minPrice)`, возвращающую новый массив товаров дороже заданной цены.
3. Реализуйте `getProductNames(cart)`, возвращающую массив названий товаров.
4. Реализуйте `calculateCategoryTotals(cart)`, возвращающую объект, где ключ — категория, а значение — общая стоимость товаров этой категории с учётом количества.
5. Реализуйте `changeQuantity(product, quantity)`, возвращающую копию товара с новым количеством, не изменяя исходный объект.
6. Реализуйте `applyDiscount(cart, discountPercent)`, возвращающую новую корзину со скидкой на каждый товар. Не изменяйте исходный массив и исходные объекты. Объясните, как обеспечено копирование.
7. Реализуйте `printProduct({ name, price, quantity })`, использующую деструктуризацию параметра.
8. Создайте функцию с параметром rest, принимающую любое количество товаров и возвращающую их суммарную стоимость. Покажите вызов функции с использованием spread.
9. Реализуйте итеративную функцию подсчёта количества всех единиц товара в корзине. Затем устно объясните, как выглядел бы рекурсивный вариант и какое условие остановки ему необходимо.
10. Проверьте решение на пустой корзине.
