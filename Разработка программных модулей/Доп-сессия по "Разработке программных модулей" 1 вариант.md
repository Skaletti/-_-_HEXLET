### Задание 2. Цепочка промисов и обработка ошибок

Дан код:

```js
function getPrice() {
  return Promise.resolve(100);
}

getPrice()
  .then((price) => price * 2)
  .then((price) => {
    if (price > 150) {
      throw new Error('Слишком высокая цена');
    }

    return price;
  })
  .then((price) => console.log('Цена:', price))
  .catch((error) => console.log('Ошибка:', error.message));
```

1. Что будет выведено в консоль?
2. На каком этапе возникает ошибка?
3. Измените код так, чтобы ошибка обрабатывалась с помощью `async/await` и `try/catch`.

### Задание 3. Последовательный и параллельный запуск

Есть функция `loadData(id)`, которая возвращает промис с результатом загрузки данных.

Напишите два варианта функции:

- `loadSequentially()`: загружает данные с идентификаторами `1`, `2` и `3` строго по очереди и возвращает массив результатов.
- `loadInParallel()`: запускает все три загрузки параллельно и возвращает массив результатов.

Используйте `async/await` и `Promise.all()` там, где это уместно.
