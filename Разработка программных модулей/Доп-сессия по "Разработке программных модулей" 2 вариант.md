## Часть 2. Практические задания

### Задание 1. Анализ Promise

Рассмотрите код:

```js
const task = new Promise((resolve) => {
  setTimeout(() => resolve(5), 100);
});

task
  .then((value) => value + 3)
  .then((value) => {
    console.log(value);
    return value * 2;
  })
  .then((value) => console.log(value));
```

1. Какие значения будут выведены в консоль и в каком порядке?
2. Объясните, как передаётся результат между обработчиками `.then()`.

### Задание 2. Обработка ошибок в async/await

Дана функция:

```js
async function getUser() {
  const response = await fetchUser();
  return response.name.toUpperCase();
}
```

Предположим, что `fetchUser()` может завершиться ошибкой или вернуть `null`.

Перепишите функцию так, чтобы она:

- обрабатывала ошибку загрузки;
- не обращалась к свойству `name`, если результат равен `null`;
- возвращала имя в верхнем регистре при успешной загрузке;
- возвращала строку `'Не удалось загрузить пользователя'` при ошибке или отсутствии пользователя.

### Задание 3. Параллельные операции

Есть функции `loadProfile()`, `loadMessages()` и `loadNotifications()`. Каждая возвращает промис.

Напишите функцию `loadDashboard()`, которая запускает все три операции параллельно, дожидается их завершения и возвращает объект:

```js
{
  profile: /* результат loadProfile */,
  messages: /* результат loadMessages */,
  notifications: /* результат loadNotifications */
}
```

Предусмотрите обработку ошибки, если хотя бы одна операция завершится неуспешно.

### Задание 4. Модель состояния списка

Разрабатывается интерфейс списка товаров. Он должен отображать:

- сообщение о загрузке;
- список товаров после загрузки;
- сообщение, если список пуст;
- сообщение об ошибке, если запрос не удался.

Предложите структуру состояния и опишите, какие элементы интерфейса должны отображаться для каждого состояния. Объясните, почему состояние загрузки, пустого списка и ошибки не следует смешивать в одно логическое значение.

### Задание 5. Типы и функции TypeScript

Создайте псевдоним типа `Product` со свойствами:

- `id` — число;
- `title` — строка;
- `price` — число;
- `description` — необязательная строка.

Затем:

1. Создайте массив товаров типа `Product[]`.
2. Напишите функцию `getDiscountedPrice`, которая принимает цену и необязательный размер скидки в процентах. Если скидка не передана, используйте значение `0`. Функция возвращает итоговую цену.
3. Создайте `enum` `OrderStatus` со значениями `Created`, `Paid` и `Cancelled`.
4. Напишите функцию `formatStatus`, принимающую `OrderStatus` и возвращающую строку.
5. Приведите пример ситуации, в которой функция может иметь возвращаемый тип `never`.
