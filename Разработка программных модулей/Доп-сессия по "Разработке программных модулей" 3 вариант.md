### Задание 1. Таймеры и промисы

Определите порядок вывода и объясните его.

```js
console.log('Начало');

setTimeout(() => {
  console.log('Таймер');
}, 0);

Promise.resolve()
  .then(() => console.log('Промис'));

console.log('Конец');
```

### Задание 2. Создание промиса

Напишите функцию `checkNumber(value)`, которая возвращает промис:

- промис успешно завершается со строкой `'Число положительное'`, если `value > 0`;
- промис успешно завершается со строкой `'Ноль или отрицательное число'`, если `value <= 0`;
- промис отклоняется с ошибкой `'Передано не число'`, если `value` не является числом.

Продемонстрируйте вызов функции с обработкой успешного результата и ошибки.

### Задание 3. Последовательная загрузка данных

Есть две функции:

- `loadUser()` возвращает промис с данными пользователя;
- `loadUserPosts(userId)` возвращает промис с массивом публикаций пользователя.

Напишите асинхронную функцию `loadUserWithPosts()`, которая сначала загружает пользователя, затем загружает его публикации по `id` и возвращает объект с пользователем и публикациями. Добавьте обработку ошибок.

### Задание 4. Состояние интерфейса

Для приложения с кнопкой «Загрузить профиль» нужно предусмотреть состояния:

- данные ещё не запрашивались;
- идёт загрузка;
- данные успешно загружены;
- произошла ошибка.

Предложите структуру состояния и напишите функцию, которая имитирует загрузку профиля. Покажите, как состояние изменяется в процессе работы. Укажите, что должен отображать интерфейс в каждом состоянии.
